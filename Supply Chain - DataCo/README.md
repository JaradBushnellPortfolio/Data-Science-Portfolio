# DataCo Smart Supply Chain Analytics

**Dataset:** [DataCo Smart Supply Chain for Big Data Analysis (Kaggle)](https://www.kaggle.com/datasets/alinoranianesfahani/dataco-smart-supply-chain-for-big-data-analysis/code)

## 01. Supervised Learning, Classification
- Feature engineering and predictor selection
- Logistic regression, random forest, and K-nearest neighbors (K-NN)
- Train/test splitting and data leakage prevention
- Model evaluation and performance comparison
- Business interpretation of classification results

## 02. Machine Learning, Forecasting & Inventory Optimization
- Feature engineering for demand forecasting
- LightGBM, XGBoost, and random forest
- Hyperparameter tuning with GridSearchCV
- Forecast evaluation and model comparison
- Inventory replenishment and optimization

## 03. Regression & Forecasting Methods
- Simple linear regression
- Multiple linear regression
- Random forest regression
- Machine learning-based time series forecasting
- Logistic regression

## 04. Statistical Analysis & Hypothesis Testing
- One-way and two-way ANOVA
- Welch's t-test
- Pairwise Welch's t-tests with Holm correction
- Two-proportion z-tests
